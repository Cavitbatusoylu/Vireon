    Proje Dokümantasyonu

    Vireon; katmanlı mimari ile geliştirilmiş dijital banka çekirdek sistemi simülasyonudur.

    • Sunum Katmanı: ASP.NET Core Web API + web arayüzü (PWA)
    • İş Katmanı: TransactionManager, FraudModelService, NeonAIService
    • Veri Katmanı: Entity Framework Core + VireonContext
    • Veritabanı: SQLite — paylaşımlı vireon_local.db
    • Demo hesapları uygulama açılışında otomatik senkronize edilir
    • Şema ve seed: EF Core migration + Program.cs

    Yerel çalıştırma: cd Vireon.PresentationLayer && dotnet run → http://localhost:5202

    About

    Detailed project information

    Digital Bank Core System

    Vireon is a database-centric digital bank core system simulation that models secure, consistent, and traceable financial transaction management.

    The system applies money transfer, account management, daily limit control, fraud analysis, and immutable ledger logic to technically model the core processing mechanism of real banking systems.

    This project is being developed by Cavit Batu Soylu, Enes Kaya, and Kerem Arslan as a Computer Engineering 2nd year final project.

    The system uses SQLite (Database/vireon_local.db), layered ASP.NET Core architecture, ACID transfers, and an immutable ledger. No automated test project (final scope). Electron desktop is optional.
