# Vireon

Bu proje, bir backend API (`VireonAPI`) ve bir frontend uygulaması (`VireonFrontend`) içermektedir.

## Proje Yapısı
- **VireonAPI**: Backend tarafını oluşturan API servisleri.
- **VireonFrontend**: Kullanıcı arayüzünü oluşturan frontend kodları.

## Kurulum ve Çalıştırma
Projeyi çalıştırmak için ilgili klasörlere giderek geliştirme sunucularını başlatabilirsiniz.
